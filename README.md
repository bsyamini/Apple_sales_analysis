# Apple Sales Analysis & Business Insights

## Project Overview
This project analyzes **Apple sales performance** using structured sales and warranty data.  
The objective is to extract **actionable business insights** from raw data using **SQL**, visualize findings in **Power BI**, and present insights through a **professional PowerPoint report**.

The project follows an **end-to-end data analytics workflow**:

> Data Collection → Data Cleaning → SQL Analysis → Dashboarding → Business Presentation

---

## Dataset Description
The project uses the following datasets:

- **Sales** – Transaction-level sales data  
- **Products** – Product details and pricing  
- **Categories** – Product category mapping  
- **Stores** – Store location and regional information  
- **Warranty** – Warranty claims and repair status  

All datasets were downloaded, cleaned, and standardized before analysis.

---

## Tools & Technologies Used
- **SQL** – Data cleaning, transformations, aggregations, and business logic  
- **Power BI** – Interactive dashboards and KPI visualizations  
- **Microsoft PowerPoint** – Executive-level business insights presentation  
- **Git & GitHub** – Version control and project documentation  

---

## Data Cleaning & Preparation
The following steps were performed using SQL:

- Removed duplicate and invalid records  
- Handled missing and inconsistent values  
- Standardized date formats and categorical fields  
- Created calculated fields and derived metrics  
- Built analytical views for reporting  

---

## SQL Analysis Performed
Key analysis includes:

- Total and category-wise sales performance  
- Product-level revenue and quantity analysis  
- Store and region-based sales trends  
- Warranty claim counts and repair status analysis  
- Identification of high-performing and underperforming products  
- Analysis of the relationship between sales and warranty claims  

---

## Power BI Dashboard
An interactive Power BI dashboard was created featuring:

- **KPIs**: Total Sales, Revenue, Units Sold, Warranty Claims  
- **Sales Trends** over time  
- **Product & Category Performance**  
- **Store and Regional Analysis**  
- **Warranty Status Breakdown**  

The dashboard supports drill-down analysis and data-driven decision-making.
